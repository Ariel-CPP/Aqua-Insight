Info Metode Pemodelan
Risiko Kematian Kumulatif:

Risiko kematian kumulatif dihitung menggunakan Pemodelan Stres Kontinu (Continuous Stress Modeling). Setiap parameter kualitas air dipetakan ke tingkat stres (0-100%) menggunakan fungsi keanggotaan kontinu (piecewise linear interpolation) berdasarkan batas toleransi kritis udang. Stres tertinggi diidentifikasi menggunakan operator fuzzy T-Conorm (Max-Aggregator). Kejadian penyakit historis diintegrasikan dengan Model Peluruhan Waktu (Time-Decay Boost) selama 14 hari.

Model Risiko Penyakit (Fuzzy):

*Catatan: Model fuzzy penyakit spesifik (WSSV, AHPND, EHP, IMNV) saat ini masih dalam pengembangan (in development). Model ini menggunakan pembobotan empiris parameter ekologi yang digabungkan dengan skor signifikansi klinis gejala fisik.
