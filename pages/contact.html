FAQ (Pertanyaan Umum)

Apakah data analisis saya dikirim ke server pusat?
Tidak. Aqua Insight menggunakan arsitektur serverless. Semua perhitungan, input data grid, dan pengolahan citra dilakukan secara lokal (client-side) di browser Anda. Data tidak akan meninggalkan komputer Anda kecuali Anda mengekspornya.
Bagaimana cara mengekspor hasil ke Excel?
Anda dapat menggunakan tombol "Impor CSV" untuk memasukkan data. Untuk mengekspor, sebagian modul yang mendukung (seperti Particle Analyzer) memiliki tombol Ekspor XLSX. Untuk tabel grid, Anda bisa memblok data dan copy-paste langsung ke Excel.
Browser apa yang paling direkomendasikan?
Kami merekomendasikan Google Chrome atau Microsoft Edge versi terbaru (berbasis Chromium) karena mengoptimalkan performa Canvas API dan kalkulasi JavaScript secara maksimal.
Apakah saya butuh koneksi internet?
Secara umum ya, untuk memuat file library eksternal (Chart.js, FontAwesome) dan memuat file HTML via jaringan lokal/hosting. Namun setelah aplikasi termuat sepenuhnya di browser, Anda bisa bekerja secara offline (tanpa koneksi luar).
